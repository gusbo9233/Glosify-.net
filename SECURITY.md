# Security policy

## Reporting a security problem

Please do not open a public issue for a possible security vulnerability. Use
[GitHub private vulnerability reporting](https://github.com/gusbo9233/Glosify-.net/security/advisories/new)
instead. Include the affected page or API, the steps needed to reproduce the problem,
and the impact you observed. Do not include real user data, credentials, or access
tokens.

## Supported version

This is a personal portfolio project. Security fixes are applied to the latest version
on the `master` branch and the deployment at [glosify.se](https://glosify.se). Older
commits and local forks are not supported releases.

Reports are handled on a best-effort basis. I will confirm the issue, avoid publishing
sensitive details before a fix is available, and credit the reporter when they want to
be credited.
