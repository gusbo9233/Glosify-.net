01 · Request path

A deliberate composition root.

Program.cs configures service lifetimes, authentication schemes, fallback authorization, antiforgery validation, rate-limit partitions, security headers, telemetry, and endpoints. This creates a single auditable place for cross-cutting behavior.

1AuthenticateCookie or bearer token establishes user context
2ProtectRate limit, authorization, antiforgery, validation
3ExecuteController delegates to a scoped service
4ObserveMetrics and traces capture important operations

02 · Data and storage

Relational state and binary assets stay separate.

Azure SQL

EF Core maps users, vocabulary, quizzes, attempts, classrooms, books, translations, assistant threads, and AI credit records to SQL Server.

Azure Blob Storage

Book documents and cacheable media are stored as blobs, while the database retains ownership and metadata.

Resilient connections

SQL retry policies and cold-start-friendly timeouts account for transient cloud failures and serverless database wake-up.

Schema evolution

Checked-in EF Core migrations make database changes reviewable and repeatable across environments.

03 · AI and speech

Model calls are treated as infrastructure, not controller logic.

Typed clients and orchestration services handle model selection, function tools, structured results, scene state, and failure translation. Azure AI Foundry is the primary generative platform, with Azure Speech supporting recognition authorization and text-to-speech.

04 · Real-time collaboration

Two channels, two responsibilities.

SignalR provides classroom chat and presence-style updates through a dedicated hub. Azure Communication Services supplies calling identities and tokens for richer live communication. Keeping these concerns separate prevents a single real-time abstraction from owning unrelated state.

The fallback authorization policy requires authentication by default. Public routes and static assets are explicitly opted out, making protected access the safe default.

05 · Reliability and security

Production controls live next to the product code.

Rate limiting

Credential, AI, TTS, book translation, speaking, and classroom write paths receive purpose-specific partitions and budgets.

Security headers

A restrictive Content Security Policy, HSTS, referrer policy, frame protection, and content-type controls reduce browser attack surface.

Observability

OpenTelemetry traces and metrics flow to Azure Monitor when Application Insights is configured.

Failure handling

Exception filters and boundary-specific errors keep external service failures from leaking implementation detail to clients.
