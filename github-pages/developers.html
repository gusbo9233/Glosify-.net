01 · System shape

Server-rendered core, focused browser clients.

Glosify is an ASP.NET Core MVC application. Controllers own HTTP concerns, scoped services hold application logic, Entity Framework Core maps domain entities to SQL Server, and Razor views render the UI. Feature-specific JavaScript handles interactive sessions such as quizzes, the book reader, speaking scenes, and classroom collaboration.

02 · Capability map

Features are organized as vertical slices.

Vocabulary & quizzes

Word sets, public collections, flashcards, typing practice, sentence work, quiz attempts, and custom templates.

Books

PDF upload, blob-backed storage, browser reading, text extraction, page-level translation, and vocabulary capture.

AI learning

Assistant tool calling, structured vocabulary generation, image text extraction, saved context, and credit accounting.

Speaking

Foundry-backed scene agents, browser speech recognition, text-to-speech, session state, and structured coaching.

Classrooms

Membership, invitations, assignments, shared content, live chat, and Azure Communication Services calling.

Accounts & API

Cookie-based web identity, bearer-token mobile endpoints, external login providers, policy authorization, and antiforgery protection.

04 · Design boundaries

Interfaces isolate changing infrastructure.

Services such as book storage, generative AI, speech, quiz sessions, and classroom operations are consumed behind interfaces. The composition root selects implementations and lifetimes, which keeps controllers small and makes infrastructure-heavy behavior testable.

BoundaryResponsibilityWhy it matters
ControllersHTTP, authorization, validation, status codesWeb concerns stay out of domain services
Application servicesFeature rules and orchestrationLogic can be tested without rendering views
Infrastructure adaptersAzure, database, speech, storage, model accessExternal dependencies remain replaceable
View/browser layerPresentation and interaction stateProgressive enhancement keeps page flows legible
