Core experiences

One product. Three reinforcing loops.

01

Build vocabulary

Collect words from PDFs, public collections, assignments, or focused word sets—with translations and contextual examples kept close.

02

Practice recall

Move from recognition to production using flashcards, typing sessions, sentence work, and configurable custom quizzes.

03

Speak naturally

Enter guided AI scenes, speak through the browser, and receive structured coaching after each turn.

Engineering breadth

A modern .NET system backed by managed Azure services.

The project spans interaction design, domain modeling, data persistence, real-time collaboration, generative AI, speech, security, observability, testing, and continuous delivery.

See system architecture
01

Application

.NET 10, ASP.NET Core MVC, Razor views, JavaScript, and responsive CSS deliver a server-rendered product with focused client-side interactions.

02

Data & identity

Entity Framework Core, Azure SQL, ASP.NET Core Identity, and Azure Blob Storage support relational state, accounts, and book assets.

03

AI & communication

Azure AI Foundry, Azure Speech, Azure Communication Services, and SignalR power tutoring, voice, calling, and live classroom experiences.

04

Operations

OpenTelemetry, Azure Monitor, rate limiting, security headers, xUnit, and GitHub Actions make reliability part of the implementation.
